# Contributing

Thank you for contributing to this Python student project.

## 1. How to Report an Issue

- Describe the problem clearly.
- Explain what happened.
- Provide the steps needed to reproduce the issue.
- Use a clear and descriptive title.

## 2. How to Suggest a Feature

- Describe the feature you would like to add.
- Explain why the feature would be useful.
- Keep the suggestion clear and simple.

## 3. How to Create a Branch

Create a new branch for your changes:

```bash
git checkout -b feature-name
```

## 4. How to Make Changes

- Make the required changes in your branch.
- Keep changes focused on the issue or feature.
- Write clear and readable code.

## 5. How to Test Changes

- Run the project after making changes.
- Check that the changes work as expected.
- Make sure existing functionality is not unnecessarily affected.

## 6. How to Create a Pull Request

- Commit your changes.
- Push your branch.
- Create a pull request.
- Clearly describe what you changed.

## 7. Basic Coding Guidelines

- Use clear and meaningful names.
- Keep the code simple and readable.
- Use consistent formatting.
- Add comments when they are helpful.
- Avoid unnecessary changes.
