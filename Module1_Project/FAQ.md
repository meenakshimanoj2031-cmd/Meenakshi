# Frequently Asked Questions

## Is Python free to install?

Yes. Python is open-source software and can be downloaded without a purchase from [python.org](https://www.python.org/).

## Which Python version should I install?

For a new setup, install the latest stable Python 3 release offered on the official downloads page, unless a class, project, or organization specifies a particular version.

## Do I need to install Python for every project?

Python itself is installed on the computer. Individual projects may use virtual environments to keep their package dependencies separate; those can be created later with Python's built-in `venv` module.

## What is `pip`?

`pip` is Python's package installer. Use it through the launcher, for example `py -m pip install package-name`, so it targets the Python installation selected by `py`.

## How can I start Python interactively?

Open PowerShell and enter `py`. The `>>>` prompt means the interactive Python interpreter is running. Enter `exit()` to leave it.

## Where should I get Python?

Use the official downloads page at [python.org/downloads](https://www.python.org/downloads/) to avoid unofficial or modified installers.

## Conclusion

Python can be installed on Windows in a few steps using the official installer. Selecting the PATH option, reopening the terminal, and checking the `py` and `pip` commands confirms that the setup is ready. Keep this guide nearby when configuring a new computer, and use official Python resources or your device administrator for additional help.
