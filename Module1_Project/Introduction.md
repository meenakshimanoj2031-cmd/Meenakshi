# Introduction

Python is a popular, general-purpose programming language used for automation, web development, data analysis, artificial intelligence, and education. Its readable syntax makes it approachable for beginners while its broad ecosystem also supports professional software development.

This guide explains how to install Python on a Windows computer, confirm that the installation works, and resolve a few common setup problems. The instructions use PowerShell and the official Python distribution.

## What You Will Accomplish

By the end of this guide, you will be able to:

- Install a current stable Python 3 release.
- Run Python from PowerShell.
- Check that Python and its package installer, `pip`, are available.
- Identify basic troubleshooting steps if a command does not work.

Download Python only from the official website: [python.org/downloads](https://www.python.org/downloads/).
